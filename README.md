# 星课it-从0开始的PPT高手修神记
获课：xingkeit.top/18828/从0开始的PPT高手修神记


PPT 配色修神课：色彩底层原理，快速搭配不出错的演示配色方案
配色是PPT里最容易被低估、也最容易翻车的环节。内容再好，配色一乱，观众第一眼就贴上“不专业”的标签。好消息是，演示配色不需要艺术天赋，它有一套可复用的底层逻辑和几条不出错的搭配公式。掌握原理，再套用规则，任何人都能做出体面的配色。

一、先理解色彩的三个属性：色相、明度、饱和度

所有配色问题都可以拆到这三个维度上。色相是颜色的“种类”，红橙黄绿蓝紫，决定情绪基调；明度是亮暗，决定层次和可读性；饱和度是鲜艳程度，决定视觉冲击力的强弱。新手最容易犯的错是只盯着色相挑“好看的颜色”，忽略了明度和饱和度。实际上，一套配色是否和谐，七成取决于明度和饱和度的关系，色相只占三成。

一个实用的判断方法：把PPT缩小或者眯眼看，如果画面糊成一片、分不清主次，问题一定出在明度对比不足，而不是颜色选错了。演示场景里，明度对比是信息层级的第一生产力。

二、配色前先定“角色”，不要一上来就挑颜色

专业配色的思路是“先分角色，再填颜色”。一套演示配色通常有四个角色。主色：出现频率最高、代表品牌或主题基调的颜色，占画面六成左右。辅助色：配合主色做区分和丰富，占三成。强调色：只用于关键数据、重点结论、行动按钮，占一成，饱和度通常最高。中性色：黑、白、灰和背景色，承担文字、分割线、底色，是画面的“呼吸空间”。

角色定好，选色就有了约束：主色要稳、辅助色要协调、强调色要跳、中性色要干净。没有角色意识的配色，本质是在随机堆颜色，越多越乱。

三、三条不出错的搭配公式

第一条，同色系搭配。选一个色相，用不同明度和饱和度做出三到四个层级。比如深蓝做主色、中蓝做辅助、浅蓝做背景块、亮青做强调。这是最安全、最高级的方案，适合商务汇报和正式场合，几乎不会出错。缺点是视觉冲击弱，靠明度层次和留白撑住质感。

第二条，邻近色搭配。色环上相邻的颜色，比如蓝和青、橙和黄、紫和红。保持同一饱和度和明度区间，画面统一又有变化，比同色系活泼，适合产品和创意类演示。

第三条，互补色搭配。色环上相对的颜色，比如蓝和橙、紫和黄。冲击力最强，但最容易翻车。铁律是“一主一辅，比例悬殊”：大面积用一个色，另一个只做小面积强调，绝不对半分。同时把其中一个色的饱和度降下来，避免两个高饱和色打架。

四、快速落地的实操流程

第一步，确定一个主色。来源可以是品牌色、行业惯用色（科技蓝、金融深蓝、环保绿、教育橙），或者从演示主题的一张高质量图片里吸取主色。吸色是新手最快的捷径，图片本身的色彩关系已经经过摄影师调校，吸出来的颜色天然协调。

第二步，用工具生成配色板。基于主色，让配色工具生成同色系或邻近色的辅助色和强调色，限定在三到四色以内。颜色数量是纪律：主色加辅助色加强调色不超过四种，中性色另算。超过四种，观众就开始觉得乱。

第三步，落到页面角色上。背景用中性色或极浅的主色 tint；标题用主色的深色版本；正文用深灰而非纯黑，减轻刺眼感；关键数字和结论用强调色；图表用主色和辅助色的不同明度区分系列，不要每个系列一个花哨颜色。

第四步，检查对比度。正文文字与背景的对比度要足够，深色背景配浅字、浅色背景配深字是基本原则。用对比度检测工具过一遍，正文对比度至少达到可读标准，强调色只用于大字或色块，不要用于小字正文。

五、场景化配色建议与常见误区

商务汇报：深蓝或深灰做主色，白和浅灰做背景，一个亮色做强调，克制、可信。产品发布：可以大胆用高饱和主色加对比强调色，深色背景衬托，营造科技感。教育培训：暖色系或蓝绿色系，饱和度适中，友好不刺眼。数据报告：主色用于主要数据系列，辅助色区分次要系列，强调色只标异常值和关键结论。

常见误区有五个。一是颜色太多，每个标题一个色，画面像调色盘；二是纯黑纯白硬碰硬，对比过强导致视觉疲劳；三是高饱和色大面积铺底，刺眼且廉价；四是红绿直接搭配，色盲用户无法区分，涉及涨跌和正负对比时要用蓝橙替代或加形状标记；五是忽视投影环境，投影仪会压暗画面、偏色，正式场合的配色要在实际投影设备上预演，适当提高明度和对比度。

配色的本质是信息设计，不是装饰。先想清楚每个颜色在画面里承担什么角色，再用同色系、邻近色、互补色三条公式约束选择，最后用对比度和投影环境做验收。把这套流程固定下来，配色就从“凭感觉”变成“按规则执行”，稳定产出专业感。
